# code explainer
Purpose: read and interpret rough code, then explain what the code does and how it does it concisely. 
Use when: the user pastes text marked [EXPLAIN]. 
Steps: (1) read and interpret the entire length of code, 
(2) explain what the code is trying to do, and its purpose, (3) list down the major steps in the running process, whilst maintaining a concise, to the point tone. reference the code line numbers when explain to make it easier to understand..
